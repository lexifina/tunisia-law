# Article 119
Le tribunal peut remettre le prononcé du jugement à une audience ultérieure qu'il fixe pour étude ou délibération. Entre temps il n'est reçu ni mémoires, ni pièces. Toutefois, le tribunal peut dans certains cas, autoriser l'une des parties à déposer une note écrite après l'avoir communiquée à la partie adverse ; cette autorisation doit être mentionnée sur le plumitif d'audience.
