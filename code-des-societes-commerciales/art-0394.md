# Article 394
L'associé commanditaire ne peut s'immiscer dans la gestion de la société même s'il est muni d'un mandat. Dans le cas «où» il s'immisce, les dispositions de l'article 71 du présent code lui sont applicables.
La participation au « conseil de surveillance » prévue à l'article 395 du présent code ne constitue par une immixtion dans la gestion de la société.
