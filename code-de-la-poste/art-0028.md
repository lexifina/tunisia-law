# Article 28
Outre les sanctions administratives prévues à l'article 27 du présent code, est puni d'une amende allant de 1000 à 10000 dinars tout opérateur agréé selon les modalités prévues par le présent code qui n'a pas respecté les conditions d'exercice de l'activité postale et les dispositions du cahier des charges prévu par l'article 4 du présent code ou qui n'a pas assuré les services postaux de base dont il a la charge.
