# Article 1162
Lorsque le mandat a été donné par plusieurs personnes pour la même affaire, le mandat ne peut être révoqué que de l'adhésion de tous ceux qui y ont concouru. Cependant, lorsque l'affaire est divisible, la révocation opérée par l'un des intéressés éteint le mandat pour la part de celui qui l'a révoqué. (Le 2 paragraphe a été abrogé par la loi n°59-129 du 5 octobre 1959 promulguant le code de commerce).
