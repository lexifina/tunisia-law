# Décret n° 2012-1974 du 20 septembre 2012, portant ratification d'un mémorandum d'entente entre le gouvernement de la République Tunisienne et le gouvernement de l'Etat du Qatar dans les domaines de la formation professionnelle.

أمر عدد 1974 لسنة 2012 مؤرخ في 20 سبتمبر 2012 يتعلق بالمصادقة على مذكرة تفاهم بين حكومة الجمهورية التونسية وحكومة دولة قطر في مجالات التكوين المهني.

- Signature : 2012-09-20
- Entrée en vigueur retenue : 2012-10-03 (law-93-64)
- Ministère : وزارة الشؤون الخارجية
