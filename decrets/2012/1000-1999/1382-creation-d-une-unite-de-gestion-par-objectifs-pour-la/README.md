# Décret n° 2012-1382 du 1er août 2012, portant création d'une unité de gestion par objectifs pour la réalisation du projet de construction d'une unité pénitentiaire à Belli du gouvernorat de Nabeul et fixant son organisation et les modalités de son fonctionnement.

أمر عدد 1382 لسنة 2012 مؤرخ في 1 أوت 2012 يتعلق بإحداث وحدة تصرف حسب الأهداف لإنجاز مشروع بناء وحدة سجنية ببلّي من ولاية نابل، وبضبط تنظيمها وطرق سيرها.
