# Décret n° 2012-1685 du 22 août 2012, fixant la concordance entre l'échelonnement des grades du statut de contrôle des dépenses publiques et les niveaux rémunération.

- Signature : 2012-08-22
- Entrée en vigueur retenue : 2012-09-16 (law-93-64)
- Ministère : رئاسة الحكومة
