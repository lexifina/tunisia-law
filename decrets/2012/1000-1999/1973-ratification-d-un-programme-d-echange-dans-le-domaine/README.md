# Décret n° 2012-1973 du 20 septembre 2012, portant ratification d'un programme d'échange dans le domaine culturel entre le gouvernement de la République Tunisienne et le gouvernement de la République de Turquie pour les années 2012, 2013 et 2014.

أمر عدد 1973 لسنة 2012 مؤرخ في 20 سبتمبر 2012 يتعلق بالمصادقة على برنامج تبادل في الميدان الثقافي بين حكومة الجمهورية التونسية وحكومة الجمهورية التركية للسنوات 2012 و2013 و2014.

- Entrée en vigueur retenue : 2012-10-03 (law-93-64)
- Ministère : وزارة الشؤون الخارجية
