# Décret n° 2012-3256 du 13 décembre 2012, fixant les procédures de réintégration des agents publics ayant bénéficié de l’amnistie générale et de régularisation de leurs situations administratives.

أمر عدد 3256 لسنة 2012 مؤرخ في 13 ديسمبر 2012 يتعلق بضبط إجراءات العودة إلى العمل وتسوية الوضعية الإدارية للأعوان العموميين المنتفعين بالعفو العام.

- Signature : 2012-12-13
- Entrée en vigueur retenue : 2012-12-23 (law-93-64)
- Ministère : رئاسة الحكومة
