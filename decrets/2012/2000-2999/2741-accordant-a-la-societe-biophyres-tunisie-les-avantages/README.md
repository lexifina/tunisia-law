# Décret n° 2012-2741 du 13 novembre 2012, accordant à la société « Biophyres Tunisie » les avantages prévus par l'article 52 du code d'incitation aux investissements.

أمر عدد 2741 لسنة 2012 مؤرخ في 13 نوفمبر 2012 يتعلق بإسناد شركة "Biophyres Tunisie" الامتيازات المنصوص عليها بالفصل 52 من مجلة تشجيع الاستثمارات.

- Entrée en vigueur retenue : 2012-11-21 (law-93-64)
