# Décret n° 2012-2482 du 16 octobre 2012, portant ratification d'un mémorandum d'entente dans le domaine du transport entre le gouvernement de la République Tunisienne et le gouvernement de la République de Turquie.

أمر عدد 2482 لسنة 2012 مؤرخ في 16 أكتوبر 2012 يتعلق بالمصادقة على مذكرة تفاهم في مجال النقل بين حكومة الجمهورية التونسية وحكومة الجمهورية التركية.

- Signature : 2012-10-16
- Entrée en vigueur retenue : 2012-10-28 (law-93-64)
- Ministère : وزارة الشؤون الخارجية
