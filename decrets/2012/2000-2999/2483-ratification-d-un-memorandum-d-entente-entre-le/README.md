# Décret n° 2012-2483 du 16 octobre 2012, portant ratification d'un mémorandum d'entente entre le gouvernement de la République Tunisienne et le gouvernement du Royaume du Maroc pour la coopération dans le domaine des ressources hydrauliques.

أمر عدد 2483 لسنة 2012 مؤرخ في 16 أكتوبر 2012 يتعلق بالمصادقة على مذكرة تفاهم بين حكومة الجمهورية التونسية وحكومة المملكة المغربية للتعاون في مجال الموارد المائية.

- Signature : 2012-10-16
- Entrée en vigueur retenue : 2012-10-28 (law-93-64)
