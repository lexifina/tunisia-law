# Décret n° 2012-648 du 2 juillet 2012, portant création d’une unité à la Présidence du Gouvernement chargée de suivre et de superviser l’exécution des programmes du gouvernement.

أمر عدد 648 لسنة 2012 مؤرخ في 2 جويلية 2012 يتعلق بإحداث وحدة برئاسة الحكومة مكلفة بمتابعة ومراقبة تنفيذ برامج الحكومة.

- Signature : 2012-07-02
- Entrée en vigueur retenue : 2012-07-11 (law-93-64)
- Ministère : رئاسة الحكومة
