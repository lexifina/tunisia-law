# Décret n? 2012-354 du 17 mai 2012, portant répartition des crédits du budget de l'Etat ouverts par la loi n? 2012-1 du 16 mai 2012, portant loi de finances complémentaire pour l'année 2012.

أمــر عــدد 354 لسنـة 2012 مـؤرخ فـي 17 ماي 2012 يتعلق بتوزيع إعتمادات ميزانية الدولة المفتوحة بمقتضى القانون عـدد 1 لسنة 2012 المؤرخ في 16 ماي 2012 والمتعلق بقانون المالية التكميلي لسنة 2012.

- Signature : 2012-05-17
