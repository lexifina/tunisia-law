# Décret n° 2012-629 du 13 juin 2012, portant modification du décret n° 2008-2047 du 2 juin 2008, fixant l'indemnité allouée aux membres du collège du comité général des assurances prévue par l'article 184 du code des assurances.

أمر عدد 629 لسنة 2012 مؤرخ في 13 جوان 2012 يتعلق بتنقيح الأمر عدد 2047 لسنة 2008 المؤرخ في 2 جوان 2008 المتعلق بتحديد المنحة المسندة لأعضاء مجلس الهيئة العامة للتأمين المنصوص عليها بالفصل 184 من مجلة التأمين.
