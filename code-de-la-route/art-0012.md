# Article 12
Les constructeurs de véhicules doivent indiquer, dans un document remis à l'acheteur, les valeurs des pressions de gonflage qu'ils recommandent pour les différents types de pneumatiques qu'ils livrent.
Pour les voitures particulières, ces indications doivent comporter au moins les valeurs recommandées dans les deux cas d'utilisation ciaprès :
a) Véhicule à pleine charge ;
b) Utilisation de longue durée sur les routes.
