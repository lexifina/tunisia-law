# Article 366
Le capitaine du navire est déchargé de toute responsabilité: a- dans le cas d'infraction visée à l'article 395 paragraphe 2 du présent code s'il prouve qu'il a rempli tous ses devoirs de surveillance ou si le délinquant est découvert, b- dans le cas d'infraction visée à l'article 395 paragraphe 3 du présent code s'il prouve qu'une avarie sérieuse a nécessité le déroutement du navire et à condition que ces événements aient été consignés au journal de bord avant la visite des services des douanes.
